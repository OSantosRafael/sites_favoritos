# Meus Sites Favoritos

Página web simples desenvolvida como atividade acadêmica para guardar meus sites favoritos.

## 🌐 Acesse o site

**https://osantosrafael.github.io/sites_favoritos/**

## 📋 Sobre o projeto

A página exibe 5 sites favoritos, cada um com:
- Nome do site
- Captura de tela do site
- Link direto para acesso
